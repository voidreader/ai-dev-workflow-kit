# 문서 최적화

에이전트 문서는 갱신만 쌓여 단조 증가한다. **지금 지켜야 할 규약만 남기고** 나머지를 덜어낸다.

## 실행

1. **검사** — `python3 .claude/skills/docs-optimization/scan.py`. 문서 경로를 인자로 주면 그것만 본다.
   **처음 쓰기 전에 `scan.py` 상단 설정 블록의 코드 루트를 프로젝트에 맞춘다** — 기본값은 `Assets`다.
2. **판정** — 검사가 낸 후보를 아래 4분류 중 하나로 정한다. 스크립트는 후보만 고르고, 판정은 그 문단을 읽고 한다.
3. **리포트** — 항목마다 `문서:행 · 현재 서술 · 조치 · 절감 바이트`를 표로 내고 승인을 받는다. 승인된 항목만 반영한다.
4. **적용** — 아래 형식으로 삭제하거나 옮긴다.
5. **검증** — 크기를 재측정하고 `git diff --stat`을 요약한다. 옮긴 절의 포인터가 실제 경로를 가리키는지 확인한다.

완료 기준: 검사가 낸 **모든 후보가 4분류 중 하나로 판정되어** 리포트에 올랐고, 승인 항목이 전부 반영되어 크기 재측정까지 끝났다.

## 판정 4분류

| 분류 | 무엇 | 조치 |
|---|---|---|
| **규약** | 지금 코드를 만질 때 지켜야 할 것, 배선 규약, 함정("조용히 실패한다") | 유지 |
| **죽은 서술** | 존재하지 않는 심볼을 설명 | 삭제 |
| **이력** | 날짜 박힌 경위, 폐기된 대안, 시도했다 되돌린 기록 | 삭제 + 출처 |
| **배치 이탈** | 참조 코드가 다른 폴더에 절반 이상 | 그 폴더로 이동 |

함정과 실패 사례는 이 문서들의 핵심 가치다 — 날짜가 붙어 있어도 **지금 코드를 만질 때 밟을 수 있으면 규약**이다.

## 검사 결과 읽기

- **★가 붙은 죽은 심볼이 1순위다.** 그 문장이 폐기를 말하면서 심볼도 사라진 것이라 삭제가 확실하다.
- **배치 이탈은 추상 계약에 적용하지 않는다.** 구현이 한 폴더에만 있어도 계약은 상위 계층에 두는 것이 정상이다 — 그 타입이 상위 계층의 다른 타입을 쓰고 있으면(같은 네임스페이스라 `using` 없이 참조하는 경우 포함) 이동 대상이 아니다. 계층은 현재 구현 분포가 아니라 의도한 확장 범위가 정한다.
- 금지 규칙의 심볼(`Resources.Load`처럼 "쓰지 않는다"고 적힌 것)은 코드에 없는 것이 정상이다. 규약으로 판정한다.
- Unity·서드파티 타입도 게임 코드에 없으면 후보로 뜬다. 프로젝트 것인지 헷갈리면 `git log -S<심볼> --oneline -1`로 과거에 존재했는지 확인한다.

## 적용 형식

**삭제 + 출처** — 덜어낸 자리에 한 줄을 남긴다.

> 근거·이력: `docs/specs/2026-08-13-<주제>-design.md` · 커밋 `9dba48cd`

**이동** — 대상 폴더에 `CLAUDE.md`가 없으면 신설하고 절을 통째로 옮긴 뒤, 원 위치에 포인터를 남긴다.

> 상세는 [`<하위 폴더>/CLAUDE.md`](<상대경로>)로 이관됐다 — 그 디렉토리 아래 파일을 다룰 때 로드된다.
